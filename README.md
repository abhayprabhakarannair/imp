# imp

Firmware for an ESP32-S3 that wakes machines on its LAN and reports whether they are up, controlled over MQTT. Board: ESP32-S3-WROOM-1 N16R8 dev kit.

Deployment values (Wi-Fi, broker, credentials, wake targets) come from `site.h`, generated by [homelab](https://github.com/abhayprabhakarannair/homelab) and never committed. `site.example.h` shows the shape.

## Behaviour

- Pings every target; a target goes offline after `IMP_OFFLINE_AFTER` consecutive misses.
- `wake <target>` always sends the magic packet, even if the target still looks online: the ping state lags reality by up to `IMP_OFFLINE_AFTER` intervals.
- The BOOT button wakes the first target.
- LED (first target): green on, red off, blue blink waking, dim white unknown, amber blink no Wi-Fi; a slow blink means the broker is unreachable.

## MQTT

Topics under `IMP_TOPIC` (`home/imp`):

| Topic | | Payload |
|---|---|---|
| `meta` | retained | `{"kind":"imp","version":…,"commands":[…],"wakes":[targets]}` |
| `status` | retained, last will | `online` / `offline` |
| `state` | retained | `{"uptime_s","rssi","ip","targets":{name:{"power","last_seen_s"?,"waking_for_s"?}}}` |
| `event` | | `boot`, `wake_sent`, `wake_failed`, `up`, `down`, `wake_timeout`, `rejected`, `restarting`, `ota_start`, `ota_failed` |
| `cmd` | in | `wake <target> [source]`, `refresh [source]`, `restart [source]` |

## Build

```sh
make test                                          # host tests, ASan/UBSan
arduino-cli compile --profile devkit .             # needs site.h
arduino-cli upload --profile devkit .              # USB
./ota-upload.sh [host]                             # Wi-Fi, default imp.local
```

`src/` is plain C++ with no Arduino dependencies; `imp.ino` only wires it to the hardware and network. Enable the hooks once per clone: `git config core.hooksPath .githooks`.
